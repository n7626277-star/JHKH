# יצירת תמונות AI במייל — הכל דרך GitHub, בחינם

שולחים מייל עם נושא `תמונה: <תיאור>`, ותוך כמה דקות מקבלים תשובה עם תמונה מצורפת שנוצרה ב-AI.
כל הלוגיקה יושבת בריפו הזה. אין Google Apps Script, אין Zapier, אין שרת חיצוני — רק GitHub Actions שמתחבר ישירות ל-Gmail דרך IMAP/SMTP.

## איך זה עובד
1. GitHub Action רץ אוטומטית כל 10 דקות (`cron`).
2. הוא מתחבר לתיבת ה-Gmail שלך ומחפש מיילים **שלא נקראו** עם נושא שמתחיל ב-`תמונה:`.
3. הטקסט אחרי `תמונה:` הופך לפרומפט ליצירת תמונה דרך [Pollinations.ai](https://pollinations.ai) — שירות AI ליצירת תמונות, בחינם וללא מפתח API.
4. התמונה נשלחת בחזרה כקובץ מצורף לכתובת ששלחה את הבקשה המקורית.
5. המייל מסומן כ"נקרא" כדי שלא יעובד שוב.

## שלבי ההתקנה

### 1. הכנת חשבון Gmail
1. יש להפעיל **אימות דו-שלבי** בחשבון הגוגל (חובה כדי ליצור App Password): https://myaccount.google.com/security
2. יוצרים **App Password** ייעודי: https://myaccount.google.com/apppasswords — בוחרים "Mail" ומעתיקים את הסיסמה בת 16 התווים שמתקבלת (לא הסיסמה הרגילה של החשבון!).
3. חשוב: ל-IMAP צריך להיות מופעל בהגדרות Gmail (בד"כ מופעל כברירת מחדל). ניתן לוודא ב-Settings → Forwarding and POP/IMAP.

### 2. יצירת הריפו ב-GitHub
1. יוצרים ריפו חדש ב-GitHub (מומלץ **ציבורי (public)** — כך ריצות ה-Action בחינם וללא הגבלת דקות. ריפו פרטי מוגבל למכסת דקות חינמית חודשית).
2. מעלים אליו את כל הקבצים מהתיקייה `image-mailer` (כולל `.github/workflows/generate-image.yml`, `scripts/package.json`, `scripts/check-and-send.js`).

### 3. הגדרת Secrets בריפו
נכנסים ל: **Settings → Secrets and variables → Actions → New repository secret**, ומוסיפים שניים:

| שם ה-Secret | ערך |
|---|---|
| `GMAIL_USER` | כתובת ה-Gmail המלאה שלך |
| `GMAIL_APP_PASSWORD` | ה-App Password בן 16 התווים מהשלב הקודם (בלי רווחים) |

### 4. הפעלה
- ה-Action יתחיל לרוץ אוטומטית כל 10 דקות לפי הלו"ז (`cron`) שבקובץ ה-workflow.
- אפשר גם להריץ אותו ידנית: בטאב **Actions** בריפו → בוחרים ב-workflow **"Check Email and Send AI Image"** → **Run workflow**.
- כדי לבדוק שהכל עובד: שולחים מייל לעצמך (מכתובת אחרת, או אפילו מאותה כתובת) עם נושא:
  ```
  תמונה: חתול חמוד רוכב על אופנוע
  ```
  ותוך כ-10 דקות (או מיד אם מריצים ידנית) תקבל תשובה עם תמונה מצורפת.

## התאמות אפשריות
- **תדירות הבדיקה**: לשנות את `cron: '*/10 * * * *'` בקובץ ה-workflow. לדוגמה `*/5 * * * *` לבדיקה כל 5 דקות (ריצות תכופות יותר צורכות יותר דקות אם הריפו פרטי).
- **מילת המפתח בנושא**: לשנות את `SUBJECT_PREFIX` בקובץ `scripts/check-and-send.js` (למשל לאנגלית: `image:`).
- **גודל/סגנון התמונה**: אפשר להוסיף פרמטרים נוספים לכתובת ה-URL של Pollinations (למשל `&model=flux`), לפי [התיעוד שלהם](https://pollinations.ai).

## עלויות (הכל חינמי)
- **GitHub Actions**: חינמי לחלוטין בריפו ציבורי. בריפו פרטי — 2000 דקות בחודש בחינם, שמספיקות בקלות לתדירות של כל 10-15 דקות.
- **Gmail SMTP/IMAP**: חינמי, במגבלת שליחה של כ-500 מיילים ביום.
- **Pollinations.ai**: שירות ציבורי חינמי ליצירת תמונות, ללא צורך במפתח API.

## אבטחה
- ה-App Password נשמר כ-Secret מוצפן בגיטהאב ולעולם לא מוצג בלוגים.
- מומלץ לא לשתף את הריפו את ה-workflow logs פומבית עם מידע רגיש (ברירת המחדל בגיטהאב לא חושפת ערכי secrets בלוגים בכל מקרה).
